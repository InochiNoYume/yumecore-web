Política de privacidad

Última actualización: 12 de octubre de 2026

Esta política explica qué categorías de información pueden intervenir cuando utilizas el sitio web público de YumeCore o el bot en una comunidad de Discord, para qué pueden utilizarse y cómo plantear una consulta.

Importante: el tratamiento concreto depende de las funciones activas, la versión desplegada, los servicios conectados y la configuración del servidor. No envíes datos sensibles innecesarios.

1. Alcance

Esta política cubre el sitio público de YumeCore y el bot cuando se utiliza para gestionar solicitudes en Discord. No cubre las prácticas de privacidad de Discord, GitHub ni las de los administradores de cada comunidad.

2. Datos que pueden tratarse

  • Datos de Discord: identificadores de usuario, servidor, canal, rol o mensaje y nombres visibles cuando sean necesarios.
  • Contenido: mensajes, respuestas de formularios, motivos y archivos compartidos dentro de un ticket.
  • Configuración: categorías, canales, roles y opciones seleccionadas por administradores.
  • Historial: eventos de gestión, notas internas y registros operativos necesarios para seguimiento y auditoría.
  • Transcripciones: contenido necesario para generar una transcripción cuando la función esté habilitada.
  • Datos técnicos: eventos de interacción, errores y datos operativos generados por la implementación.

3. Finalidades

Los datos pueden utilizarse para crear y gestionar tickets, dirigir solicitudes, aplicar la configuración de la comunidad, mantener la seguridad, diagnosticar errores y prevenir abusos.

4. Sitio web y tecnologías similares

El sitio es estático y no requiere una cuenta para funcionar. No incorpora intencionalmente publicidad ni analítica de terceros. GitHub Pages puede procesar registros técnicos necesarios para entregar y proteger el sitio.

5. Almacenamiento y conservación

YumeCore utiliza Supabase para conservar configuración y registros del sistema. Las transcripciones se almacenan en un bucket privado de Supabase Storage. Un servidor puede publicar una copia de texto en su canal de transcripciones; en ese caso, los permisos de Discord controlan el acceso.

Los tickets cerrados, sus transcripciones privadas en Supabase Storage y las copias de transcripción gestionadas por el bot se conservan hasta 90 días después del cierre y se programan para eliminación automática.

6. Eliminación al salir de una guild

Cuando Discord confirma que YumeCore ha salido de una guild, el bot elimina de forma aislada la configuración, datos y recursos de Storage asociados a esa guild_id. La operación no debe afectar a otras comunidades. Una indisponibilidad temporal de Discord no se interpreta como una salida y no dispara esta eliminación.

7. Acceso y divulgación

El personal autorizado de cada servidor puede acceder a las solicitudes según los permisos de Discord. El acceso debe limitarse a quienes necesiten atender el caso. Los proveedores técnicos pueden tratar datos conforme a sus funciones y condiciones.

8. Responsabilidad de los servidores

La comunidad decide quién puede abrir, ver y atender tickets. Sus administradores deben configurar permisos correctamente, informar a sus miembros cuando corresponda y evitar recopilar información innecesaria.

9. Consultas y eliminación

Para consultar, corregir o solicitar la eliminación de información relacionada con un ticket, contacta primero con el equipo del servidor donde lo abriste. Para consultas sobre YumeCore o esta política, utiliza el servidor oficial de soporte o la invitación permanente discord.gg/7QTeThJvrV.

10. Seguridad

Se recomienda limitar los permisos del bot, proteger las credenciales, restringir el acceso a canales privados y evitar publicar datos de tickets en canales abiertos. Ningún sistema conectado a Internet puede garantizar seguridad absoluta.

11. Cambios

Esta política puede actualizarse si cambian las funciones, los proveedores o los requisitos legales. La versión vigente y su fecha se publicarán en esta página.
