YumeCore
Plataforma de soporte

Todo lo necesario para gestionar tickets.

YumeCore está pensado como una plataforma configurable, no como un panel de categorías fijas. Cada servidor define sus propios flujos.

01 · TICKETS

Paneles y categorías

Crea varios paneles, categorías, canales de destino, archivo y papelera. Los nombres y la presentación se adaptan a cada comunidad.

02 · FORMS

Formularios personalizados

Solicita información antes de abrir un caso y muestra las respuestas junto al ticket para que el equipo tenga contexto.

03 · ACCESS

Permisos por acción

Define qué roles pueden reclamar, transferir, cerrar, archivar, gestionar participantes y realizar acciones administrativas.

04 · WORKFLOW

Ciclo de vida

Cierra, reabre, archiva o mueve tickets a papelera con validaciones según el estado del caso.

05 · AUTOMATION

Automatización

Configura recordatorios, inactividad, límites de tickets activos, cooldown y protección anti-spam.

06 · PRIVACY

Transcripciones privadas

Las transcripciones se guardan en un bucket privado de Supabase. Las copias publicadas en Discord dependen de los permisos del canal.

07 · AUDIT

Historial y auditoría

Registra eventos relevantes del sistema y permite configurar canales para operaciones, auditoría y errores.

08 · DATA

Aislamiento por servidor

La configuración y los datos se separan por guild_id. Al salir de una guild confirmada, se limpia únicamente esa comunidad.

09 · BACKUP

Copias de seguridad

Exporta y restaura configuraciones con validaciones para impedir mezclar datos entre comunidades.

10 · UI

Interfaz moderna

Las acciones persistentes usan menús desplegables; los modales se reservan para introducir texto cuando hace falta.
